PLC, HMI and 8 solenoid valves running the show (230 parts in Fusion 360 and counting)
* **DAW:** a standalone ESP32-S3 DJ console with lossless FLAC playback, real-time DSP, dual displays and an I2S DAC (lossless audio, lossy sleep schedule)
* **learning ROS 2 the hard way:** taking apart an open-source autonomy stack to see how the navigation actually works (or ROS 2 is learning me, unclear)
* **autonomous drone CV:** onboard detection and autonomy for a competition drone (the drone has opinions)
